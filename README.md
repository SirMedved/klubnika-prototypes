# Прототипы сайта питомника клубники (klubnika-minsk.by)

Прототипы для выбора дизайна сайта klubnika-minsk.by.

- `index.html`, `catalog.html`, `sort.html`, `cart.html`, `faq.html`, `order.html`, `about.html` в корне:
  прототип-1 (минималистичный, отклонён родителями 2026-10-25, архив, не развивать)
- `variant2/`: актуальный прототип — клон Super Klubnika ~90%, жёлтый фон #E8F04D,
  голубая лента/футер #4385BE, красные акценты #C03E35, лого logo-berries-v2.svg,
  100 сортов из выгрузки Тильды (sorts-data.js), корзина из прототипа-1 (app.js общий)
- `analysis/`: снапшоты Super Klubnika (Wayback + live), выгрузка Тильды и чистые данные сортов

Статус и решения: заметка в Obsidian «Проект сайта питомника клубники (klubnika-minsk.by) - ТЗ и решения»,
раздел «Вариант 2: клон Super Klubnika». Шаблон страниц: shell (шапки/лента/футер/скрипты)
идентичен на всех страницах variant2, проверяется дифф-скриптом; меняется только внутренность main.
